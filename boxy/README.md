# Boxy

**What is Boxy?**
Boxy is a tool that allows users to launch, monitor, and use container-based vllm and scientific applications remotely, with a focus on ease-of-use.

This tool is primarily written in Python and provides core functionality for SSH connectivity, job scheduling, and seamless interaction with containerized environments. It boasts a modular architecture that enables users to tailor their own environments and applications. Users can choose from various container runtimes—such as Charliecloud or Podman, as well as HPC schedulers like SLURM or Flux, and define both containers and applications to meet their specific needs.

### How:
* The tool currently needs a simpler modular structure This can be accomplished by creating wrappers for commonly used commands and features. The first being SLURM allocation, and simple Podman commands.
* Process management can be accomplished with the Python Subproccess library.
* SSH will be done via a separate library or by issuing commands through Python. It is not known what will be the most effective and easiest to use.
* I/O and persistence techniques will have to be considered to save models, states, inferences, or any other data generated by or needed for the application.
  
### Goals:
* An easy-to-use application that allows users to use and interact with their own containers and applications on HPC systems.
* A modular framework that allows for the addition of new functionality and other container runtimes.
* A publication detailing itÕs use case and performance on different systems.
